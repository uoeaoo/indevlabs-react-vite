Please follow the instructions described here to run this project on you PC. 

1/ Clone this repo by writing a following command in your terminal: git clone https://github.com/username/your-repo-name.git

2/ CD to project: cd your-repo-name

3/ Install dependencies: npm install

4/ Run the project: npm run dev 

5/ Open http://localhost:5173

----------------------------------------------------------------------------------------

You must have Node.js version >= 18 / npm or yarn 
All data saved in localStorage, it means if you will restart your browser data will be still in there. 
To clear localStorage you need to open dev tools -> application -> localStorage -> RMB click on http://localhost:5173 -> clear
